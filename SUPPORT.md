# Support

Voxel4D is maintained as an open research proof of concept. Community support is provided on a best-effort basis through the repository's public issue tracker and GitHub Discussions after publication.

| Request type | Preferred channel |
|---|---|
| Reproducible defect | GitHub bug report |
| Feature or design proposal | GitHub issue or discussion |
| Documentation clarification | GitHub issue or pull request |
| Security vulnerability | Private report under [SECURITY.md](SECURITY.md) |
| Conduct concern | Private report under [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |

Please provide your operating system, compiler and CMake versions, GLM installation method, exact build command, runtime output, and a minimal reproduction where possible. The project does not provide guaranteed response times, paid support, or warranties of fitness for production, safety-critical, surveillance, or high-stakes applications.
