# Governance

## Purpose

Voxel4D is an early-stage open research project. Its governance prioritizes reproducible evidence, technical clarity, inclusive collaboration, and honest communication about implementation maturity.

## Maintainer model

The project uses a lightweight maintainer model. Maintainers are responsible for reviewing pull requests, managing releases, enforcing project policies, and protecting the repository's technical direction. Until a named maintainer team is published in the GitHub repository settings, repository administration remains with its owner.

Contributors may propose changes through issues and pull requests. Consistent contributors who demonstrate sound technical judgment, respectful collaboration, and sustained maintenance may be invited to become maintainers.

## Decisions

Normal changes are decided through review by at least one maintainer. Substantial changes—such as public API breaks, new dependencies, data-format changes, sensor ingestion, new physics models, or AI integrations—should begin with a written issue or design discussion. Maintainers seek consensus; when consensus is not reached, the responsible maintainer makes the final decision and records its rationale.

## Releases

Pre-1.0 releases follow semantic-versioning intent:

| Change type | Suggested version action |
|---|---|
| Bug fix, documentation, or compatible improvement | Increment patch version |
| New feature or intentional API adjustment | Increment minor version |
| Major redesign or project maturity transition | Increment major version when appropriate |

Every release should have a tagged commit, changelog entry, source archive generated by GitHub, build/test evidence, and a clear statement of limitations.

## Conflict resolution

Technical disagreements should remain evidence-based and respectful. Behavioral concerns are handled under the [Code of Conduct](CODE_OF_CONDUCT.md). Security issues follow [SECURITY.md](SECURITY.md). If a conflict cannot be resolved publicly, maintainers may move the discussion to a private channel and publish a concise outcome where appropriate.
